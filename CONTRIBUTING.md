# Contributing to AEC GenAI Bench

Thank you for your interest in contributing! AEC GenAI Bench is under active development, and contributions from the research community are welcome.

## Ways to contribute

- **Report problems or ask questions** by opening a GitHub issue.
- **Propose new benchmark tasks or datasets** for AEC-related applications.
- **Improve evaluation protocols, metrics, or code** in `evaluation/` and `code/`.
- **Submit results** for the leaderboards (see `leaderboards/` and `results/`).
- **Improve documentation and examples** in `documentation/` and `examples/`.

## Getting started

1. Fork the repository and create a branch from `main`.
2. Make your changes, keeping each pull request focused on one topic.
3. Open a pull request describing what changed and why.

## Guidelines

- Follow the existing directory structure described in the [README](README.md).
- Make results reproducible: include the model/system version, settings, and the scripts or commands used.
- Do not commit large simulation outputs, credentials, or proprietary data. Share large files through an external host and link to them.
- Only contribute material you have the right to share.
