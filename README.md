# AEC GenAI Bench

A public benchmark and evaluation resource hub for generative AI in Architecture, Engineering, and Construction (AEC).

## Overview

**AEC GenAI Bench** is a research project for developing, evaluating, and sharing benchmarks and evaluation resources for generative AI applications in the Architecture, Engineering, and Construction (AEC) domain.

The project aims to support **systematic, transparent, and reproducible evaluation** of AI models and systems on AEC-related tasks, including building energy modeling, building science, architectural design, engineering analysis, and other domain-specific applications.

The repository serves as the **public-facing project hub** for benchmark datasets, evaluation protocols, results, leaderboards, documentation, and research resources that are ready to be shared with the research community.
